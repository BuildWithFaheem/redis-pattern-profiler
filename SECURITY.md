# Security Policy

## Supported versions

The latest released minor version receives security fixes.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Use GitHub's private vulnerability reporting:
<https://github.com/BuildWithFaheem/redis-pattern-profiler/security/advisories/new>

Please include:

- A description of the issue and its impact
- Steps to reproduce
- The affected version

You can expect an acknowledgement within a few days. If the report is valid,
you will be credited in the advisory unless you prefer otherwise.
