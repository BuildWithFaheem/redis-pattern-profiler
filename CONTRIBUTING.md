# Contributing to redis-pattern-profiler

Thanks for considering a contribution.

## Getting started

```bash
git clone https://github.com/BuildWithFaheem/redis-pattern-profiler.git
cd redis-pattern-profiler
npm install
npm test
```

## Before you open a pull request

- Open an issue first for anything larger than a small fix, so we can agree on
  the approach before you spend time on it.
- Keep the change focused. One concern per pull request.
- Add or update tests covering the behaviour you changed.
- Run `npm run lint` and `npm test` locally.

## Commit messages

This project uses [Conventional Commits](https://www.conventionalcommits.org/):

```
feat: add support for X
fix: handle empty input in Y
docs: clarify the Z option
```

## Use of AI tools

AI-assisted contributions are welcome, with one requirement: **disclose it**.
A line in the pull request description such as "written in part with the
assistance of generative AI" is enough.

This is not a judgement about AI. It tells the reviewer how deeply to read the
diff, which is genuinely useful information. Please also make sure you
understand and have tested the change yourself — a pull request you cannot
explain will be closed regardless of how it was produced.
